# Вариант №10

Местному торговцу киосками с хот-догами нужна система точек продаж для операторов киосков с хот-догами
Пользователи: около пятидесяти операторов ларьков с хот-догами, тысячи клиентов в округе (через социальные сети).
Требования:
должен быть легким по размеру — ноутбук слишком громоздкий, чтобы его можно было эффективно использовать при приготовлении хот-догов на улице.
разрешить скидки
отслеживать продажи по времени и местоположению
отправлять обновления запасов продуктов мобильным сотрудникам по управлению запасами (которые приезжают к месту с запасами)
обеспечить интеграцию с социальными сетями, чтобы клиенты могли получать уведомления о том, что поблизости находится киоск с хот-догами.
экспортировать информацию в формате, импортируемом инструментами бухгалтерского учета
Дополнительный контекст:
вынужден заняться этой разработкой, потому что нынешние смешанные способы отслеживания продаж требуют слишком большого количества ручных усилий.
время завершения важно
важнее создать решение, которое не потребует замены через 3 года.
нет серьезных бюджетных ограничений
